# 채널 랜딩 리디자인 — 결정과 목업

- 작성일: 2026-07-30
- 대상: `frontend/src/components/ChannelLanding.tsx` (랜딩 화면 한정)

랜딩이 밋밋하다는 판단에서 시작해, 우표 갤러리를 "게시판에 붙인 우표"로 읽히게 만드는 작업이다. 목업 세 개를 만들어 비교한 뒤 아래를 정했다.

## 목업

브라우저로 열면 된다. 실제 앱의 우표 CSS(톱니 마스크·종이 질감·소인 SVG)를 그대로 가져다 썼으므로 화면과 거의 같게 보인다.

| 파일 | 내용 |
|---|---|
| `stamp-mount.html` | 우표 부착 방식 4안(테이프 1곳 / 테이프 2곳 / 압정 / 부착물 없음) + 소인과의 겹침 확인 |
| `stamp-buttons.html` | 버튼 5안(톱니 / 소인 도장 / 에어메일 / 종이 라벨 / 현재). hover 동작함 |
| `board-warmth.html` | 배경 온도 슬라이더. 질감은 고정하고 `background-color`만 바꿔 hex를 뽑는다 |

## 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 우표 부착 | **마스킹테이프 우상단 1곳** | 우표는 붙이는 물건이라 압정보다 은유가 맞다. 우표마다 이미 −10°~9° 기울기가 있어 "손으로 붙인 결과"로 읽힌다. 안읽음 소인이 **좌상단**이라 테이프는 우상단이어야 겹치지 않는다 |
| 버튼 기본 | **종이 라벨** — 점선 테두리 + 종이 질감, 고스트 변형 있음 | 점선이 톱니를 암시만 한다. 크기를 가리지 않고 포커스 링도 멀쩡하다 |
| `입장하기` | **소인 도장** — 화면당 하나만 | 우표를 확대해 "이걸 쓰겠다"고 결정하는 순간이라 도장 은유가 맞는다. 안읽음 소인과 같은 언어라 남발하면 시끄럽다 |
| 보조 아이콘 | 지금 형태 유지, **모서리 8px → 3px** | 종이는 둥글지 않다 |
| 배경 | **미정** | 레퍼런스 확인 후 결정. 질감은 그대로 두고 색만 조정한다 |

## 하지 않기로 한 것

- **톱니(우표 마스크)를 버튼에 쓰지 않는다.** 우표와 같은 언어라 우표가 주인공에서 내려온다. 실무적으로도 CSS 마스크가 포커스 링과 그림자를 잘라내 접근성·입체감을 함께 잃는다.
- **에어메일 테두리(빨강·파랑 빗금)를 기본으로 쓰지 않는다.** 세이지 팔레트와 색이 싸운다.
- **코르크색 배경으로 뒤집지 않는다.** 게시판다움은 커지지만 우표·버튼이 배경 쪽으로 끌려와 우표가 덜 도드라진다.

## 배경을 정할 때 주의

안읽음 소인이 **빨강(`#C2402C`)**이다. 배경 갈색을 붉은 쪽으로 잡으면 소인이 묻힌다. 노란 쪽(세피아·카키)으로 가야 소인이 산다. `board-warmth.html`의 보간도 R을 올리고 B를 낮추는 방향으로 잡아, 채도가 붙어 탁해지지 않게 했다.

## 범위

이번 변경은 **랜딩 화면만**이다. 채팅 화면과 설정 모달의 버튼은 그대로 둔다 — 랜딩에서 어울리는지 보고 확장 여부를 정한다.
