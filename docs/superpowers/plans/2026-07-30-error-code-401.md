# 오류 코드와 세션 만료 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 오류 응답에 코드를 실어 프론트가 문자열 매칭 없이 사유를 구분하게 하고, 세션이 만료되면 401로 알려 재로그인을 안내한다.

**Architecture:** `ErrorResponse`에 `code`를 추가하고 모든 예외 핸들러가 채운다. `/api/**`에는 커스텀 `AuthenticationEntryPoint`를 걸어 로그인 리다이렉트 대신 401 JSON을 반환한다. 프론트는 `ApiError`(status·code 보유)를 던지고, 401은 한 곳에 등록된 처리기가 세션을 정리한다.

**Tech Stack:** Spring Boot 4 / Spring Security 7.0.4 / Jackson 3(`tools.jackson`) / React + TypeScript

설계 문서: `docs/superpowers/specs/2026-07-30-error-code-401-design.md`

## Global Constraints

- 브랜치는 `feat/error-code-401`(이미 존재, `origin/develop`에서 분기). PR 대상은 **develop**.
- **스키마 변경 없음.** Flyway 마이그레이션 파일을 추가하지 않는다.
- 백엔드 검증은 `./gradlew test`. 테스트는 **Redis(localhost:6379)·MySQL(3306)이 떠 있어야** 통과한다.
- 프론트 검증은 `cd frontend && npm run lint && npm run build`. 유닛 테스트 러너가 없다.
- **Spring Security 7에는 `AntPathRequestMatcher`가 없다.** `org.springframework.security.web.servlet.util.matcher.PathPatternRequestMatcher`를 쓴다.
- 이 프로젝트의 Jackson은 **Jackson 3**이다. import는 `tools.jackson.databind.ObjectMapper`.
- `message` 필드는 그대로 둔다. **필드 추가만** 하므로 기존 소비자가 깨지지 않는다.
- 테스트 메서드 이름은 한글 관례를 따른다.
- 커밋 메시지·주석은 변경의 목적만 쓴다. 배경 서사 금지.

`src/main/java/com/example/springboot_realtimechat/global/exception/ApiAuthenticationEntryPoint.java`:

```java
package com.example.springboot_realtimechat.global.exception;

import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import org.springframework.http.MediaType;
import org.springframework.security.core.AuthenticationException;
import org.springframework.security.web.AuthenticationEntryPoint;
import org.springframework.stereotype.Component;
import tools.jackson.databind.ObjectMapper;

import java.io.IOException;

// API는 로그인 페이지로 리다이렉트하지 않는다. 브라우저 fetch가 cross-origin에서 막아
// 세션 만료가 네트워크 오류로 보이기 때문이다. 오류 응답과 같은 형태로 401을 준다.
@Component
@RequiredArgsConstructor
public class ApiAuthenticationEntryPoint implements AuthenticationEntryPoint {

    private final ObjectMapper objectMapper;

    @Override
    public void commence(HttpServletRequest request,
                         HttpServletResponse response,
                         AuthenticationException authException) throws IOException {
        response.setStatus(ErrorCode.UNAUTHORIZED.getStatus());
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding("UTF-8");
        response.getWriter().write(objectMapper.writeValueAsString(ErrorResponse.of(ErrorCode.UNAUTHORIZED)));
    }
}
```

`ObjectMapper`는 Jackson 3(`tools.jackson.databind`)이다. 주입되는 빈이 없거나 타입이 다르면 실제 프로젝트가 쓰는 것을 확인해 맞춰라(`RedisSubscriber`가 같은 것을 주입받는다).

```ts
// 서버가 내려주는 오류 코드를 그대로 들고 다닌다. 문구가 바뀌어도 분기가 깨지지 않게 하려는 것이다.
export class ApiError extends Error {
  readonly status: number;
  readonly code?: string;

  constructor(message: string, status: number, code?: string) {
    super(message);
    this.name = 'ApiError';
    this.status = status;
    this.code = code;
  }
}

// 401은 호출 지점이 많아 각자 확인하면 반드시 빠뜨린다. 한 곳에서 처리기를 받아 둔다.
// 등록은 App이 마운트 시 한 번만 한다.
let unauthorizedHandler: (() => void) | null = null;

export function setUnauthorizedHandler(handler: (() => void) | null) {
  unauthorizedHandler = handler;
}
```

- [ ] **Step 2: `request()`가 코드를 담아 던지게 한다**

`request()`의 `if (!response.ok) { ... }` 블록을 아래로 교체한다:

```ts
  if (!response.ok) {
    const text = await response.text();
    let message = text || `요청 실패: ${response.status}`;
    let code: string | undefined;
    try {
      const parsed = JSON.parse(text);
      if (parsed && typeof parsed.message === 'string') message = parsed.message;
      if (parsed && typeof parsed.code === 'string') code = parsed.code;
    } catch {
      /* JSON 아님 — 원문 유지 */
    }
    if (response.status === 401) unauthorizedHandler?.();
    throw new ApiError(message, response.status, code);
  }
```
